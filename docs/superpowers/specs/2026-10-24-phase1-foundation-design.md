## Design tokens

- **Colours:** one asset-catalog colour set per token in `tokens.json` (19: `bg`, `surface-1`, `surface-2`, `ink`, `ink-secondary`, `ink-tertiary`, `ember`, `ember-ink`, `ember-line`, `ember-glow`, `on-ember`, `slate`, `slate-ink`, `slate-line`, `slate-glow`, `on-slate`, `track`, `danger`, `scrim`), Any = light, Dark = dark. Generated by `scripts/gen-colors.py` from `tokens.json` so the two never drift. Swift accessors in `Color+Tokens.swift`.
- **`Accent`:** the README's struct (fill, onFill, ink, line, glow) chosen from lock state, injected via the environment.
- **Typography, `Space`, `Radius`, `Motion`, `Haptics`:** copied from README §4, §5, §7, §8. `Haptics.prepare()` exposed for the NFC phase.

## Components

**`OrbView(tone:, ringTone:, ring:, size:)`**, a port of `Orb.dc.html` `renderVals()`:
- Glow: circle 1.44 × size, offset −0.22 × size, radial gradient of the tone's glow RGB (alpha 0.5/0.34 dark, 0.42/0.32 light), fading out by 68%.
- Body: circle inset 13%, radial gradient centred at (50%, 58%) with stops hi 0 / mid .34 / deep .72 / edge 1.0, plus a soft bottom ellipse highlight, 1pt inner white 22% stroke and an outer drop shadow.
- Gloss: two white elliptical highlights (top-left large, bottom-right small).
- Ring: `Circle().trim(0, ring)` rotated −90°, stroke `max(2.5, 1.6% size)`, round caps, radius `size/2 − 1.5 × stroke`, `ember-line`/`slate-line`, glow shadow at 2.5% size; faint track only while ring < 1.
- The orb's gradient stops (hi/mid/deep/edge) are not design tokens; they live in one `OrbPalette` inside `OrbView`.
- Accessibility: one image element labelled "Sealed ember orb" / "Ember orb" / "Slate orb", as in the spec.

**`FloatingTabBar(active:)`** (tabs enum `AppTab`, since SwiftUI already has a `Tab` type): 64pt capsule on `surface-1`, 24pt side margins, 32pt from the bottom, 4 equal cells with 4pt gaps, active cell is a `surface-2` capsule with `ink` icon, inactive icons `ink-tertiary`. Icons: closest SF Symbols to the spec's custom glyphs (Modes `slider.horizontal.3`, Places `mappin`, Insights `chart.bar`); Home's circle-in-dashed-circle is drawn as a small custom `Shape` if no symbol matches. Soft shadow in both themes (dark: black 40%, y 8, blur 24; light: 10%, y 4, blur 20), per `TabBar.dc.html`. Each cell ≥ 44pt and labelled for VoiceOver.

**`PrimaryButton`**: 56pt capsule, state fill + `on-` label, `headline`, optional symbol, press scale 0.97.

## Model

```swift
enum LockSession {
    case unlocked
    case locked(since: Date)
    case emergency(relockAt: Date, duration: TimeInterval) // 5 min
}
```

The README's two-case `LockState` (`locked`/`unlocked`) stays as the accent selector: `LockSession.lockState` maps locked and emergency to `.locked` (ember owns the accent there) and unlocked to `.unlocked`.

`MockLockController` (`@Observable`) owns the session, a `passesLeft` count (mock: 3), and an injectable `now: () -> Date` so tests don't wait in real time. Methods: `simulateTagRead()`, `useEmergencyPass()`, `relockNow()`, `tick()`. The emergency state relocks itself when `relockAt` passes. Nothing is persisted; the app starts unlocked each launch.

`TimeFormat`: `m:ss` under an hour, `h:mm` from one hour (matches the spec's `fmt`).

## Home screen

Matches `Home.dc.html` at 390 × 844 (px = pt). Content sits inside the safe area with 24pt side margins and clears the tab bar.

| State | Header pill | Centre | Bottom action |
| --- | --- | --- | --- |
| Unlocked | "Deep work ▾" in `ink` | Slate orb 300, no ring; "Unlocked" (`slate-ink`, open lock) + "[2h 40m] phone-free today" | Primary "Scan" in `slate` |
| Locked | lock glyph + "Deep work ▾" in `ember-ink` | Sealed ember orb 244; timer counting **up** in `timerHero`; "Locked" in `ember-ink` | Quiet "Emergency pass · 3 left" |
| Emergency | as unlocked | Slate orb 244, ember ring = time left / 5 min; "Relocks in", timer counting **down**, "Emergency pass · 2 of 5 left" | Primary "Relock now" in `ember` |

Gear button (44pt, `surface-1` circle) opens Settings (placeholder).

**Phase 1 mock interactions:**
- Unlocked → **Scan** → the lock moment plays → Locked at 0:00.
- Locked → **tap the orb** → stands in for a tag read → unlock (`spring-unlock`, one soft haptic). The locked screen in the designs has no unlock control, so how a real unlock scan starts is an open question for Phase 4.
- Locked → **Emergency pass** link → Emergency (the hold-10-seconds pass screen comes in Phase 3).
- Emergency → **Relock now**, or the countdown hits 0 → Locked.

## Lock moment

A full-screen overlay matching `LockFrame.dc.html`, with the place pill ("Kitchen") at top and no tab bar:

| Time | What happens |
| --- | --- |
| 0 ms | Frame 1: slate orb 280 with two slate-line pulse rings, "Hold still". First rigid haptic |
| 90 ms | Second rigid haptic; tone slate → ember; ring sweeps 0 → 1 (`Motion.lock`, response 0.6, damping 0.72) |
| ~450 ms | One shockwave: three ember-line rings expand outward and fade |
| 600 ms | Settled: timer "0:00" + "Locked"; overlay crossfades into Home locked |

Reduce Motion: frame 1 → frame 4 as a 0.25 s crossfade, no sweep or ripple; haptics unchanged.

## Themes and accessibility

- Every view previewed in dark and light (`#Preview` for each Home state × theme).
- Timer uses `.monospacedDigit()`, scales via `@ScaledMetric` capped at 1.3×; exposed as one accessibility element ("Locked for 47 minutes").
- All tap targets ≥ 44pt. No borders on cards. Continuous corners.
